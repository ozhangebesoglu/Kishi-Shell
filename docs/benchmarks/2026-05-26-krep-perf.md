## Test Methodolojisi

- **Soğuk önbellek**: her koşudan önce `CONCEPT_CACHE.clear()`
- **Warm-up**: 1 ön-koşu (Python import + JIT)
- **3 ölçüm ortalaması**, p50/p95/p99 stat-grade testlerde
- `silent()` context manager veya `builtins.print = lambda *a, **k: None`
  ile stdout yutuldu (saf süre ölçümü için)
- `time.perf_counter()` mikro-saniye çözünürlüklü

## Quadrant Matrix: rg × Cython

ripgrep ve Cython'ın birbirinden bağımsız katkısını izole eden 2×2 matrix:

| Senaryo (3-run avg) | rg=Y, Cy=Y | rg=Y, Cy=N | rg=N, Cy=Y | rg=N, Cy=N |
|---|---:|---:|---:|---:|
| Kishi src `auth login` | **7.8 ms** | 9.6 ms | 2311 ms | 4177 ms |
| Kishi src `error timeout` | **11.0 ms** | 13.8 ms | 2307 ms | 4212 ms |
| Tests `auth login` | **10.4 ms** | 15.0 ms | 2318 ms | 4720 ms |
| Tests `error timeout` | **11.9 ms** | 16.6 ms | 2305 ms | 4652 ms |
| Stdlib `auth login` | **17.3 ms** | 24.7 ms | timeout | timeout |

**İçgörü:**
- **rg dominant**: rg+ → fallback 2 saniye → 7 ms = **~260x**
- **Cython etkisi**: rg açıkken %22, rg kapalıyken %80 (4177 → 2311 = 1.8x)
- **rg+Cython** = en hızlı (535x worst-to-best)

**Görülen:** rg-streaming corpus boyutuna **lineer DEĞİL**, **bulunduğu yerden bağımsız**.
17M satırlık 1 GB dosya 6 ms'de tamamlanıyor çünkü early-stop 50 match'e ulaşmadan
durduruyor. Korpus 100 GB olsa bile sonuç ~6 ms olur (ilk 50 match'in yeri belirleyici).
